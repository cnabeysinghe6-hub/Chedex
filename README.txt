CHEDEX WEBSITE
==============
Open index.html in a browser. No install or build step needed.

Folders
  index.html      all pages (Home, Services, Work, Process, About, Contact)
  css/style.css   styles and colour tokens (:root at the top)
  js/main.js      page routing, animations, services/work/process content
  assets/         your logo files

Edit content
  - Services, Work projects and Process steps: top of js/main.js (SERVICES, WORKS, STEPS)
  - Email, phone, text: index.html (replace hello@chedex.com)
  - Colours: --yellow, --ink, --white in css/style.css

Publish
  Upload the whole folder to Vercel, Netlify, GitHub Pages or any web host.
  Fonts load from Google Fonts, so the site needs internet access.
